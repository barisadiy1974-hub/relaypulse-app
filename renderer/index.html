What This Does

          
Per Anyone docs, rewards require ContactInfo @anon: WALLET in the relay's anonrc file. This panel audits it via SSH and can write it remotely.

          
MetaMask isn't embedded in Electron for now. Safest flow: copy the address from MetaMask, paste it here, then write it to the relay with Bind wallet.

          
Wallet claim/lock/reward actions are still done via the official dashboard: dashboard.anyone.io.

        

      

    


    
    

      

        
        
        
      

      

        Nyx = a curses-based full-screen monitor for the anon relay (bandwidth, connections, circuits, config, logs).
        Clicking the button opens a new Terminal window and runs
        ssh -tt <server> nyx -s /run/anon/control on the selected server.
        In the terminal: m = menu, l = logs, c = circuits, ←/→ = pages, q = quit.

        For password-auth servers, sshpass must be installed locally (brew install hudochenkov/sshpass/sshpass).

        In the terminal: F5 = tree view, F6 = sort column, F9 = kill, q = quit.
        


        Requirement: htop must be installed on the server (apt install htop -y). Falls back to top automatically if not installed.
        For password-auth servers, sshpass must be installed locally.

        Reads/writes the selected server's /etc/anon/anonrc file over SSH.
        Save + Restart runs anon --verify-config after writing; on error it restores from .bak and does not restart the service.
        Apply bandwidth preset adds the BandwidthRate 10 MBytes / Burst 15 MBytes / AccountingMax 4 TBytes / month 1 00:00 block to the selected server and restarts it.
        Apply preset to ALL applies the same setting to all servers (careful: cannot be undone).

          Both are measured from the real on-chain Σ difference (not a projection). Hourly = difference between consecutive Σ samples (~one sample per hour), Daily = day-over-day increase of Σ — matches the dashboard exactly. Hourly fills in ~1 hour, daily on day 2. Chart = actual daily earnings over recent days.
        

      


      

        

          ⚠ Low-Earning Relays
          —
          
        

        

          Relays whose bandwidth is normal and uptime is mature (≥3 days) but whose daily reward is 40%+ below the fleet median. The drop isn't from bandwidth → likely an uptime-streak/consensus issue. (Only relays with real on-chain data are compared.)

About

          
Each tick runs a single SSH command per server (/proc/net/dev, ss, /proc/stat, /proc/meminfo, df, systemctl is-active anon). Rates are computed by diffing byte counters between ticks. Logs come from journalctl -u anon or /var/log/anon/*.
